Alternando função atendimento para chat

Quando este botão é ativado, os scripts são personalizados para a função de chat, e quando está desabilitado, a função de telefone é ativada. O segundo botão traz os scripts previamente cadastrados na plataforma anterior.

Criando categoria e modelo de script

Aqui, é possível cadastrar uma categoria para filtrar. Tudo o que for relacionado ao aspecto financeiro pode ser categorizado como "financeiro", por exemplo, possibilitando a busca rápida de modelos dentro do editor de texto. Para isso, é necessário criar um atalho começando com o símbolo "#". Caso não haja esse atalho, é possível cadastrar um modelo de texto, porém ele não será carregado automaticamente. Nesse caso, será necessário copiar o texto manualmente e colá-lo no editor de texto.

Criando, alternando e excluindo cards

O bloco de atendimento permite que sejam adicionados vários cards para vários clientes simultaneos. Não há limite para a quantidade de cards. É possível tambem alternar a posição entre eles e atribuir uma cor para ajudar na memorização.

Copiando e colando valor da fatura rapidamente

O bloco de atendimento oferece a flexibilidade de adicionar múltiplos cards para diversos clientes simultaneamente, sem qualquer limite de quantidade. Além disso, você pode alternar suas posições conforme necessário e também atribuir cores personalizadas para auxiliar na memorização e identificação.

Usando os atalhos

Após criar os modelos de script, é possível utilizá-los dentro do editor de texto. Basta inserir o atalho iniciando com "#" e, em seguida, pressionar "Enter". Isso carregará automaticamente o modelo desejado, facilitando a utilização e agilizando o processo de digitação.

Funções de cada botão no editor de texto

  1. Transferir a informação copiada.
  2. Gerar a descrição copiando até o ponto final (.)
  3. Copiar todo o atendimento.
  4. Preencher os campos com as informações do chat.
  5. Guardar temporariamente a pendência.
  6. Apagar o conteúdo do campo de texto.
  7. Copiar a informação do campo de texto.
  8. Colar o valor da fatura copiado no sistema com formatação.
  9. Adicionar o texto padrão para o rádio.
  10. Copiar a informação contida nos campos do formulário.
  11. Campo para validação e correção do CPF ou CNPJ
  12. Campo para adicionar novos cards.
